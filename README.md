# Vietnam Travel Website

This is a monorepo for a travel website about Vietnam. It contains a Next.js frontend and a Ktor backend.

## Structure

- `apps/web`: Next.js frontend
- `apps/api`: Ktor backend

## Getting Started

To get started, run the following commands from the root of the repository:

```
npm install
npm run dev
```

This will start the frontend and backend servers concurrently. The frontend will be available at `http://localhost:3000` and the backend at `http://localhost:8080`.
